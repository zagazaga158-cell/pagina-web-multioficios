# Historias de usuario

| ID | Historia de usuario |
|---|---|
| HU01 | Como cliente, quiero buscar y consultar servicios filtrados por oficio (electricidad, gasfitería, carpintería, etc.), para encontrar el profesional técnico capacitado que necesito. |
| HU02 | Como profesional de oficio, quiero registrar mi perfil, certificaciones técnicas, tarifas y disponibilidad de turnos, para ofrecer mis servicios a los clientes de la plataforma. |
| HU03 | Como cliente, quiero gestionar los servicios técnicos en mi solicitud de contratación con fecha y horario, para planificar adecuadamente la visita del especialista. |
| HU04 | Como cliente, quiero confirmar y pagar la orden de servicio mediante pago protegido en custodia, para garantizar la realización del trabajo con respaldo de la plataforma. |
| HU05 | Como administrador, quiero validar las acreditaciones técnicas y antecedentes de los profesionales postulantes, para autorizar únicamente especialistas calificados. |
| HU06 | Como cliente, quiero consultar el estado de mis servicios contratados y calificar al especialista con estrellas y comentarios, para retroalimentar la calidad del servicio. |
