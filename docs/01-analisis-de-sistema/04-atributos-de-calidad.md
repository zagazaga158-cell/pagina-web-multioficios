# Atributos de calidad

| ID | Atributo de calidad | Escenario de calidad |
|---|---|---|
| AC01 | **Rendimiento** | Las consultas de técnicos por oficio, perfiles certificados y cálculo de cotizaciones deben responder rápidamente, incluso con alta afluencia de usuarios simultáneos. |
| AC02 | **Disponibilidad** | El sistema debe permanecer disponible de manera continua para atender solicitudes de servicio regulares y urgencias técnicas domésticas. |
| AC03 | **Escalabilidad** | El sistema debe admitir un incremento progresivo en el registro de profesionales y contrataciones de servicios sin degradar el rendimiento general. |
| AC04 | **Seguridad** | Los datos personales, domicilios de los clientes, expedientes de los profesionales y transacciones de pago deben resguardarse contra accesos no autorizados. |
| AC05 | **Mantenibilidad** | La plataforma debe estar desacoplada en capas (Clean Architecture) para permitir incorporar nuevos oficios o pasarelas de pago sin impactar los módulos existentes. |
