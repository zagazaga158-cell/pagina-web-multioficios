# ConectaOficios · Plataforma Web de Servicios Multioficios

## Docente
Ing. Lizbeth Jaico Quispe

## Descripción
Plataforma web académica de servicios multioficios que conecta clientes (hogares y empresas) con profesionales y técnicos capacitados y certificados (electricistas, gasfiteros, carpinteros, cerrajeros, pintores, entre otros), garantizando seguridad, transparencia de tarifas y protección en la contratación.

## Caso de estudio
**ConectaOficios**: Ecosistema digital de intermediación de oficios técnicos y servicios para el hogar/empresas con pago protegido, evaluación por estrellas y verificación de especialistas.

## Curso
IS-488 Arquitectura de Software · Universidad Nacional de San Cristóbal de Huamanga (UNSCH)
